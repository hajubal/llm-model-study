# 초급 · 먼저 정의하고, 규칙으로 잡고, 제대로 잰다

초급에서는 모델을 학습하지 않는다. 위협 모델과 라벨 경계를 먼저 정하고, 단순한 규칙 탐지기를 만든 뒤,
고정 데이터에서 오탐과 미탐을 측정한다. 마지막에 제로샷 모델을 같은 채점기로 비교한다.

| # | 레슨 | 산출물 |
|---|---|---|
| 01 | 위협 모델과 라벨 경계 | 어노테이션 결정 10개 |
| 02 | 규칙 기반선 | `runs/rule-pred.jsonl` |
| 03 | 평가 기초 | macro F1, attack recall, benign FPR 표 |
| 04 | 제로샷 모델 | 규칙 vs 모델 비교 메모 |

초급 수료 기준은 높은 점수가 아니라, 정상 보안 문장을 왜 hard negative로 따로 봐야 하는지 설명할 수 있는 것이다.
