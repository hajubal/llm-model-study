# 고정 교육용 벤치마크

`gold.jsonl`은 작은 스모크 벤치마크다. 모델 품질을 주장하기 위한 데이터가 아니라 파이프라인과 지표의 의미를
확인하기 위한 것이다. `negatives.jsonl`은 보안 용어를 포함하지만 정상인 hard negative만 모았다.

주의:

- 모두 교육용 합성 문장이다.
- 이 파일을 train에 넣지 않는다.
- 공개 데이터셋과 운영 로그를 추가할 때는 라이선스, 동의, 개인정보, 중복 원문을 점검한다.
- 제품 성능 평가는 더 크고 독립적으로 검수된 비공개 holdout으로 별도 수행한다.
