# 고급 · 간접 입력과 우회를 견디는 운영 방어층 만들기

고급은 분류 모델을 제품 방어층으로 가져가는 과정이다. 모델 하나로 안전을 보증하지 않고, 입력 출처와 긴 문서,
표현 변형, 정책 threshold, 지연시간, 회귀 게이트를 함께 다룬다.

| # | 레슨 | 산출물 |
|---|---|---|
| 01 | 간접 Prompt Injection과 긴 문서 | 위치별/chunk 평가 |
| 02 | 의미 보존 적대적 변형 | robustness 비교표 |
| 03 | 규칙+모델 하이브리드 게이트 | block/review/allow 정책과 CI 게이트 |
| 04 | ONNX와 지연시간 | torch vs ONNX p50/p95 |
| 05 | 독립 벤치마크와 리포트 | 재현 가능한 보안 모델 보고서 |
| 06 | 캡스톤 | 데이터→모델→정책→리포트 전 과정 |

운영에서는 탐지 결과를 `allow/block` 두 값으로만 쓰기보다, 확신이 낮은 사례를 `review`나 제한된 도구 경로로
보내는 정책을 권장한다. 분류 결과를 권한 상승의 근거로 사용하지 않는다.
