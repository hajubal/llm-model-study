# 01 · 데이터 스키마와 누수 없는 분할

랜덤 행 분할은 같은 템플릿의 단어만 조금 바꾼 문장을 train과 test 양쪽에 넣는다. 모델이 공격 개념이 아니라
템플릿을 외워도 높은 점수가 나온다. 따라서 `group_id`로 원문·템플릿·번역·변형을 묶고 그룹 전체를 한 split에 둔다.
공용 분할기는 label과 language를 함께 층화해 각 split의 기본 언어 분포도 유지한다.

검사 항목:

- 모든 ID가 고유한가?
- label과 source 값이 계약 안에 있는가?
- 같은 group_id가 둘 이상의 split에 있는가?
- label/source/language 분포가 한쪽으로 쏠렸는가?
- 정답을 노출하는 메타데이터가 모델 입력에 들어가는가?

`inspect_data.py`는 첫 네 항목을 자동 확인한다. 의미상 중복과 라벨 품질은 사람이 표본 검수해야 한다.
